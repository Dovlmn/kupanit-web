# קופנית

תקציב משפחתי שבועי: רישום הוצאות משני טלפונים, פירוט חודשי מדפי אשראי, קופת חיסכון.

המאגר הזה מכיל רק את הממשק (`app.html`, `style.css`, `app.js`). אפליקציית האנדרואיד (kupanit-android) טוענת אותו בכל פתיחה, כך ששינוי כאן מגיע לטלפונים בלי התקנה מחדש. הנתונים עצמם נשמרים ב-Firebase, מאחורי כניסה, ורק שני החשבונות של המשפחה יכולים לגשת אליהם.
